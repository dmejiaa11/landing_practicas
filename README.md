# Homely – Landing Page

Web hecha con HTML, CSS y JavaScript.

## Archivos

- index.html
- about.html
- contact.html
- news.html
- styles.css
- script.js
- _headers (esto lo he visto porque me lo recomiendan para optimizar la web)

## Como abrirla

Abrir index.html con live server.

## Funcionalidades JS

# 1. Menú hamburguesa con accesibilidad (aria-expanded) 
Es el boton de 3 rayas de la version movil que hace que al pulsar, se abra o que cierra.
- https://www.ashleysheridan.co.uk/blog/Making+an+Accessible+Hamburger+Menu

# 2. Navbar con clase al hacer scroll
Cuando haces scroll el header cambia de aspecto.
- https://www.geeksforgeeks.org/how-to-create-a-fixed-sticky-header-on-scroll-with-css-and-javascript

# 3. Scroll suave a secciones
Hace que al cambiar de pagina no salte de golpe si no que se deslice suavenente.
- https://developer.mozilla.org/en-US/docs/Web/API/Element/scrollIntoView

# 4. Validación del formulario de contacto
Antes de enviar el formulario, con esto se ve si hay datos que estan mal, o que haya campos incompletos, despues te envia un mensaje dependiendo si es correcto o erroneo.
- https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Form_validation
- https://dev.to/mailfloss/using-javascript-for-email-validation-regex-a-practical-guide-4m6k

# 5. Galería con scroll (carousel)
Es una galeria con movimiento
- https://medium.com/@magyarn/simple-carousel-with-vanilla-js-3dd10a143ff2
